# Minimum Requirements
#
# Core platform packages (numpy/scipy/scikit-learn are installed via conda in the Dockerfile) are
# hard-pinned to current stable. Everything else is intentionally left unpinned so pip's resolver
# picks whatever's mutually compatible with the new core stack (Python 3.12, numpy 2.x, pandas 2.x) -
# most of the old ==2021-era pins here predate Python 3.12 wheels entirely and would force pip to
# try (and fail) to build them from source.
