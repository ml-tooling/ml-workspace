# Light Requirements
#
# Core platform packages are hard-pinned to current stable; the rest is left unpinned so pip
# resolves whatever's mutually compatible with the new core stack. A few packages that no longer
# have a maintained release compatible with modern Python/numpy are swapped for their current
# successor (noted inline) or dropped rather than pinned to something broken.

## ML Frameworks
# pytorch is installed via pip in the Dockerfile
# scikit-learn installed via conda
# intel-tensorflow was discontinued years ago - its MKL/oneDNN optimizations are built into stock
# tensorflow by default now
tensorflow==2.21.* # TensorFlow is an open source machine learning framework for everyone.
xgboost==3.4.* # Scalable, Portable and Distributed Gradient Boosting
statsmodels # Statistical modeling and econometrics in Python
# NOTE: mxnet-mkl / Apache MXNet has had no active release since 2022 and was moved to the Apache
# Attic (retired) - dropped rather than pinned to a release that won't install on modern Python.
networkx # Python package for creating and manipulating graphs and networks

## NLP
spacy # Industrial-strength Natural Language Processing (NLP) with Python and Cython
nltk # Natural Language Toolkit
# NOTE: the original 'fasttext' PyPI package is built against the pre-2.0 numpy C ABI and will not
# build against numpy 2.x - if fasttext is actually needed, use one of the community numpy2-compatible
# forks (e.g. fasttext-wheel / fasttext-numpy2) instead.
beautifulsoup4 # Beautiful Soup is a library that makes it easy to scrape information from web pages.
soupsieve # A modern CSS selector implementation for Beautiful Soup.

# Images
opencv-python-headless # Wrapper package for OpenCV python bindings.
opencv-python # Wrapper package for OpenCV python bindings.
scikit-image # Image processing routines for SciPy

## Jupyter
# ipywidgets (8.x) is installed directly in the Dockerfile alongside the JupyterLab extensions;
# widgetsnbextension (the ipywidgets 7.x / classic Notebook 6 companion package) is obsolete under
# ipywidgets 8 / Notebook 7 and has been removed.
tensorboardX # TensorBoardX lets you watch Tensors Flow without Tensorflow
ydata-profiling # Generate profile report for pandas DataFrame (successor to the archived pandas-profiling)

## Others
pymongo # Mongo Client
fire # A library for automatically generating command line interfaces.
patsy # A Python package for describing statistical models and for building design matrices.
boto3 # The AWS SDK for Python
better-exceptions # Pretty and helpful exceptions, automatically
pretty-errors # Prettifies Python exception output to make it legible.
prometheus-client # Python client for the Prometheus monitoring system.
typer # Typer, build great CLIs. Easy to code. Based on Python type hints.
numba # Compiling Python code using LLVM
# NOTE: 'python-language-server' (palantir/python-language-server) has been unmaintained since 2020;
# jupyterlab-lsp 5.x / modern editors expect python-lsp-server (pylsp) instead.
python-lsp-server[all] # Python Language Server for the Language Server Protocol
pylsp-mypy # Mypy linter plugin for python-lsp-server
